Interface discard investigation - current findings

- MTU was reviewed as one possible factor. The same Cohesity MTU 1500 configuration is used across many interfaces, while only a small number show notable discard behavior.
- Across the general Cohesity interface set, RX length errors and RX drops are low, with no notable TX errors or TX drops observed.
- Separately, one Cohesity interface shows comparatively higher/increasing RX drops together with an abnormal discard-related event. This should be treated as an isolated observation and reviewed separately.
- On the Arista RX side for the interface reviewed: RX Discards = 0, RX Errors = 0, FCS Error Rate = 0, Giants = 0 and Runts = 0. PAUSE Frames In were observed, while PFC Frames In remained 0.
- On the Arista TX side: Errors Out = 0, while Output Discards are present.
- No general interface issue has been identified on the Cohesity side from the counters reviewed.
- If deeper/vendor investigation is required, NOC should provide only Arista diagnostic data not available to us in CloudVision, particularly queue/buffer/LANZ details or support logs for the relevant discard window. The same window can then be correlated with Cohesity diagnostics for vendor review.
