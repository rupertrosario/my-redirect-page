FYI, I updated TJ and WV that we had initiated the STEM process for a standardized exception request, and it is pending decision. ## Interim Excel Request Form

| Incident # | Exception Type | CI Name | Environment | Scope Type | Scope Details | Requested Exception | Business Reason | Requested By | Owner Approval | Approval Email / Evidence | Backup Team Review | Impact / Risk Notes | Expiry / Review Date | Status | Comments |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |

## Dropdown Values

| Field | Options |
|---|---|
| Exception Type | Backup Exclusion / Retention Extension |
| Scope Type | Server / VM / Database / File / Folder / Disk / NAS Path |
| Owner Approval | Pending / Approved / Rejected |
| Status | New / Under Review / Approved / Implemented / Closed |

## Notes

- Approval Email / Evidence should include the approval email text, email attachment reference, or incident attachment reference.
- Status is used only to show where the request currently stands: received, under review, approved, implemented, or closed.
